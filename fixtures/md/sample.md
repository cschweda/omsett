# Omsett

Drop a file. Pick a format. **Nothing leaves your device.**

## What it converts

- Pictures
- Data, such as *JSON* and CSV
- Subtitles
  - and lyrics

1. Drop a file
2. Pick a format

| Format | Kind |
| ------ | ---- |
| PNG | Picture |
| JSON | Data |

> Files are converted in the tab you have open.

Read more at [omsett.com](https://omsett.com), or see the picture: ![The Omsett mark](mark.png "A mark").
